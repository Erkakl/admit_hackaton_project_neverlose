# DaDuino + Kendryte K210: AI Vision Robot & Gesture Control Simulator
### Кейс «Motion. Камера вместо джойстика» · Admit Hackathon

Проект представляет собой комплексное инженерное решение задачи бесконтактного управления мобильным роботом на базе платформы **DaDuino** и модуля компьютерного зрения **Kendryte K210 (OV2640)**.

В состав репозитория входят:
1. **Интерактивный 3D-симулятор полигона** (Three.js + MediaPipe Hands) с реалистичной кинематикой дифференциального привода, физическими размерами робота ($25 \times 17 \times 12$ см), трекингом AprilTag ID:6 и мини-игрой эволюции шасси.
2. **Прошивка реального робота** на MicroPython/MaixPy для процессора Kendryte K210 (`k210_firmware/main.py`).
3. **Демонстрационное видео** работы реального робота с трекингом метки и распознаванием жестов (`videoofrobot.mp4`).

## 🚀 Быстрый запуск проекта

### Вариант 1. Запуск в один клик (Windows)
Просто запустите двойным кликом скрипт:
```cmd
start.bat
```
Скрипт автоматически проверит зависимости (`npm install`), запустит локальный сервер разработки и откроет симулятор в браузере по адресу `http://localhost:3000/`.

### Вариант 2. Запуск через консоль
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск dev-сервера
npm run dev
```

## 🕹️ Управление в симуляторе

### 1. Бесконтактное управление жестами через веб-камеру (MediaPipe)
Окно веб-камеры и туториала жестов является **плавающим** — его можно перетаскивать мышью в любое удобное место экрана за верхнюю шапку:

| Жест | Действие робота | Описание |
| :---: | :---: | :--- |
| ✊ | **Газ / Вперед** | Сожмите пальцы в кулак для поступательного движения |
| ✋ | **Стоп / Тормоз** | Раскройте ладонь пальцами вверх для мгновенной остановки |
| 💪 | **Задний ход** | Наклон предплечья или пальцы вниз |
| ↔️ | **Руление (Поворот)** | Смещение кисти руки вправо или влево относительно центра кадра |

### 2. Автономное следование за AprilTag ID:6
- Перемещайте метку **AprilTag ID:6** по полигону левой кнопкой мыши (ЛКМ).
- Робот отслеживает метку сенсором K210, рассчитывает ошибку по углу $\Delta \theta$ и дистанции $\Delta d$, удерживая заданную дистанцию (55 см).
- Доступен режим автоблуждания метки (**Auto-wander**) для проверки автоматической стабилизации.

### 3. Клавиатурное управление
- Клавиши `W`, `A`, `S`, `D` или стрелки на клавиатуре.

## 🎮 Мини-игра: Эволюция робота («Нищий» ➔ «Cyber Bot»)

В левую панель интегрирована система эволюции робота:
1. **Начальный ранг: «Нищий» (Scrap Bot v0.1)**:
   - Корпус: картонная коробка с синей изолентой и надписью маркером.
   - Колеса: ржавые крышки от консервных банок.
   - Камера: старая разбитая вебка на деревянной палочке.
   - Скорость: ограничена до $0.35$ м/с, магнит отсутствует.
2. **Сбор золотых монет (🪙)**:
   - Монеты разбросаны по арене, плавно парят и вращаются.
   - Робот собирает монеты жестами или меткой (+10 🪙 за штуку со звуковым эффектом).
3. **Ветки мастерской улучшений**:
   - **Двигатели:** *Ржавый мотор* ➔ *Редукторы TT-Motor (0.7 м/с)* ➔ *Cyber Brushless (1.15 м/с)*.
   - **Корпус:** *Картон* ➔ *Акриловый DaDuino v3.2 со стойками* ➔ *Кибер-карбон со спойлером и неоном*.
   - **Сенсор K210:** *Вебка на палке* ➔ *Фирменный модуль K210 OV2640* ➔ *KPU Neuro + лазер*.
   - **Магнит:** *В упор* ➔ *Неодимовый магнит (0.9 м)* ➔ *Ионный грави-захват (1.8 м)* — физически притягивает монеты на расстоянии.
4. **Ранги:**
   - ⚪ `РАНГ: НИЩИЙ`
   - 🔵 `РАНГ: DADUINO v3.2`
   - 🟣 `РАНГ: CYBER BOT`

## 🤖 Прошивка реального микроконтроллера Kendryte K210

Код для бортового вычислителя робота находится в директории [`k210_firmware/main.py`](./k210_firmware/main.py).

### Аппаратная конфигурация:
- **Процессор:** Kendryte K210 (Dual-Core RISC-V 64-bit @ 400 MHz, аппаратный нейроускоритель KPU).
- **Сенсор изображения:** OmniVision OV2640 (QQVGA $160 \times 120$ для высокого FPS).
- **Дисплей:** ST7789 TFT $320 \times 240$.
- **Драйвер двигателей (H-Bridge):**
  - Левый мотор: `L_IA -> IO13`, `L_IB -> IO19`
  - Правый мотор: `R_IA -> IO10`, `R_IB -> IO17`
- **Аппаратные кнопки переключения режимов:**
  - `IO9`: Режим 1 — Автономное следование за AprilTag.
  - `IO12`: Режим 2 — Распознавание цветовых жестов (Color Blobs).
